# Contribution and Issue Policy

This is a source-available, owner-maintained research repository.

## Issues

Reproducibility reports, defect notices, documentation questions, and
well-scoped technical observations may be submitted through GitHub Issues.
Please include the tested commit or file hash, environment, exact command, and
the smallest reproducible case available.

Issue discussion does not grant permission to use repository materials beyond
the root [`LICENSE`](LICENSE).

## Contributions

External pull requests, patches, code, documentation, datasets, and asset
contributions are not accepted. Unsolicited pull requests will be closed
without merge.

Only the repository owner or an explicitly authorized maintainer may change
the upstream repository or its `main` branch. A public fork is an independent
copy and does not alter this repository.

The limited evaluation rights in [`LICENSE`](LICENSE) allow local installation
and execution of unmodified copies for non-commercial testing. They do not
grant modification, redistribution, sublicense, sale, derivative-work,
hosted-service, production, or commercial-use rights.
