# Contribution Policy

This is a closed-source, owner-maintained research repository.

External pull requests, patches, code, documentation, datasets, and asset
contributions are not accepted. Unsolicited pull requests will be closed
without merge.

Only the repository owner or an explicitly authorized maintainer may change
the upstream repository or its `main` branch. A public fork is an independent
copy and does not alter this repository.

Viewing and GitHub-platform forking rights arise only to the limited extent
required by GitHub's Terms of Service. They do not grant broader permission to
use, modify, redistribute, sublicense, sell, or create derivative works. See
[`LICENSE`](LICENSE).
