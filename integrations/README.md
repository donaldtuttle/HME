# Integrations

`symbolic_field_dynamics.py` is the byte-preserved Symbolic Field Dynamics v1.0 source used in the verified SFD → HME bridge.

`SFD` remains a separate DEVELOP typed realization. Its signature is converted into an HME payload through the declared `commit_to_hme(...)` adapter, which defaults to `Σ◯` for consolidation/write.
