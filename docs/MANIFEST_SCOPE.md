# MANIFEST.sha256 Scope

`MANIFEST.sha256` is the integrity manifest for the **release-bearing HME
payload**:

- active and preserved engine sources;
- packaging and requirements;
- tests;
- baseline evidence;
- public documentation;
- governance references;
- integrations;
- portable skill files and references;
- repository policy and workflow files.

The manifest intentionally excludes:

- `.git/**` and GitHub-generated metadata;
- local caches, virtual environments, outputs, and temporary files;
- binary release archives generated by GitHub; and
- `experiments/**`, whose DEVELOP runs must pin their own harness, engine,
  protocol, corpus, answer key, seed, and configuration in each result bundle.

Exclusion from the release manifest does not grant an experiment canonical
weight or weaken its own freeze requirements.

## Verification

From a clean checkout:

```bash
sha256sum --check MANIFEST.sha256
```

On macOS with BSD tools:

```bash
shasum -a 256 -c MANIFEST.sha256
```

A release should not be published when any listed file fails verification.

## Update rule

Whenever a listed file changes, regenerate its line before merge. New
release-bearing files must be added in path-sorted order. Experimental files
remain governed by their experiment-specific pins unless they are promoted into
the release-bearing payload.
