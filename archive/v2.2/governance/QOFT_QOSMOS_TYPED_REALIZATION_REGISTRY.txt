and missing type bridges across existing QOFT/QOSMOS layers.

stamped governance and adopted canon govern.

## 3. Realization Test

For a canonical operator:

O : A → B

and a runtime realization:

Oᵣ : Aᵣ → Bᵣ

the realization must declare:

encode_A : A → Aᵣ
decode_B : Bᵣ → B

A valid realization satisfies:

decode_B ∘ Oᵣ ∘ encode_A ≈ O

The meaning of ≈ must be declared:

- exact equality
- observational equivalence
- bounded approximation
- behavioral conformance
- projection onto the canonical output

For an instrumented runtime result:

Oᵣ : Aᵣ → Bᵣ × Artifact

the canonical result is recovered through:

π_B : Bᵣ × Artifact → Bᵣ

decode_B ∘ π_B ∘ Oᵣ ∘ encode_A ≈ O

Side artifacts do not change the canonical codomain.

## 4. Registry Status Vocabulary

PINNED
Exact type or ownership fixed by stamped governance.

ALIGNED
Runtime realization preserves the canonical type and role.

INSTRUMENTED
Runtime returns the canonical result plus telemetry or events.

PARTIAL
Only part of the canonical behavior is implemented.

LOCAL_ALIAS
Implementation name for an existing canonical construct.

LIFT_REQUIRED
A declared map between carrier spaces is required.

RANGE_UNRESOLVED
The value space or bounds differ across specifications.

OVERLOADED
The same glyph carries materially different roles across layers.

UNDEFINED
Canon deliberately leaves the mechanism open.

FORBIDDEN
The mapping contradicts stamped governance.

EXPERIMENT_ONLY
The realization is scoped to one experiment and carries no canonical weight.

### TRR-01: Πᴽ

Canonical ownership:

Πᴽ : Ψ × Ctx × M → Ψᴽ
ψᴽ := Πᴽ(ψ; ctx, m)

Role:

- reflexive projection
- self-model construction
- production of ψᴽ

Recognized runtime face:

Reflex(psi, ctx) → PsiReflex

Permitted realization families:

- mirror projection
- auto-encoding
- predictive self
- narrative self
- declared hybrid

Required runtime constraint:

Πᴽ must be bounded or contractive under the selected model.

Forbidden mappings:

- Π↺ must not produce ψᴽ
- Π↺ must not be called the reflexive projector
- Σ◯ must not replace Πᴽ as the canonical ψᴽ constructor

Registry status: PINNED / ALIGNED
Source anchor: D-Π-01, Canonical Ownership
Confidence: ρ̂_conf_HIGH

### TRR-03: Γ

Canonical registration:

Γ : Ψ × Ctx → G
Γ(ψ; ctx) ∈ G

Construction path:

Φ(ψ; ctx) ∈ Φ
ρ(ψ; ctx) ∈ Ρ
∇Φ(Φ, ψ) ∈ TΨ
Γ(ψ; ctx) ∈ G

Open bridge:

TΨ → G is not explicitly defined.

An instantiation must either:

1. declare G = TΨ, or
2. declare an explicit map TΨ → G.

Ownership rule:

Lift-like realization into Ψ belongs to the ⊕ mechanism policy.
Γ does not independently lift its output into Ψ.

Registry status: PINNED / LIFT_REQUIRED
Source anchor: ψᴽ-001 r2.2
Confidence: ρ̂_conf_HIGH

## 7. Experiment Registration Rule

Every experiment must declare:

- canonical operator targeted
- exact implementation targeted
- implementation type signature
- ablation substitution
- preserved inputs and outputs
- whether the intervention removes, freezes, replaces, or bypasses the operator
- which canonical behaviors are not represented
- scope of any resulting claim

Example:

Canonical target:
Ωµ : Ψ × Ctx → Ψ

Experimental implementation:
Ωµ_stub : CollapseEvent → AuditStamp

Ablation:
Ωµ_stub := no-op

Permitted conclusion:
The audit stamp has no measured effect on the selected dynamical metrics.

Forbidden conclusion:
Canonical Ωµ is non-dynamical.
